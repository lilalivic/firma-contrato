# Firmar contrato de arriendo

Pantalla que se abre en el teléfono, en la entrega del departamento, para
completar el acta, tomar las fotos de identidad y firmar.

**No guarda ni contiene ningún dato.** El contrato llega dentro del código que
se pega al abrirla, y todo ocurre en el propio teléfono: nada se envía a ningún
servidor.
